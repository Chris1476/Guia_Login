Crear Aplicación de Autenticación con ASP.NET Core 8/9 MVC, JWT y HTMX

Introducción

Esta guía te enseñará paso a paso cómo crear una aplicación completa de autenticación con ASP.NET Core 8/9 MVC desde cero. Implementarás registro de usuarios, login, confirmación de cuenta por email, restablecimiento de contraseña, y características modernas como JWT authentication y HTMX.

Características de la aplicación:
  • Registro de usuarios con confirmación por email
  • Login con autenticación JWT (stateless)
  • Restablecimiento de contraseña
  • Entity Framework Core (Database First)
  • HTMX para interactividad moderna
  • Rate Limiting para protección contra ataques
  • Arquitectura limpia con inyección de dependencias
Requisitos previos:
  • Visual Studio 2022
  • SQL Server (Express o completo)
  • SQL Server Management Studio
  • Cuenta de Gmail para envío de emails (o configurar otro SMTP)

2.2 Crear la tabla de usuarios

CREATE TABLE Usuario(
    IdUsuario INT PRIMARY KEY IDENTITY(1,1),
    Nombre VARCHAR(100) NOT NULL,
    Correo VARCHAR(150) NOT NULL,
    Clave VARCHAR(256) NOT NULL,
    Restablecer BIT DEFAULT 0,
    Confirmado BIT DEFAULT 0,
    Token VARCHAR(256) NULL,
    CONSTRAINT UK_Correo UNIQUE (Correo)
)
GO
Explicación de la estructura:
  • IdUsuario: Identificador único autoincremental
  • Nombre: Nombre del usuario (máximo 100 caracteres)
  • Correo: Email único del usuario (máximo 150 caracteres)
  • Clave: Contraseña hasheada con SHA256 (máximo 256 caracteres)
  • Restablecer: Indica si el usuario solicitó restablecer contraseña
  • Confirmado: Indica si el usuario confirmó su cuenta por email
  • Token: Token para confirmación o restablecimiento de contraseña

3.3 Generar DbContext desde base de datos existente (Database First)

Usa el comando Scaffold-DbContext para generar el DbContext y las entidades desde la base de datos existente:

Scaffold-DbContext "Server=(local);Database=DBPrueba;Trusted_Connection=True;TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Data -Context ApplicationDbContext
Nota: Este comando generará automáticamente:
  • El archivo ApplicationDbContext.cs en la carpeta Data
  • La clase Usuario.cs (entidad) en la carpeta Data
  • La configuración de la tabla en el DbContext

3.4 DbContext generado (ejemplo)

using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata;

namespace WebAppCorreo.Core.Data
{
    public partial class ApplicationDbContext : DbContext
    {
        public ApplicationDbContext()
        {
        }

        public ApplicationDbContext(DbContextOptions<ApplicationDbContext> options)
            : base(options)
        {
        }

        public virtual DbSet<Usuario> Usuarios { get; set; }

        protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
        {
            if (!optionsBuilder.IsConfigured)
            {
                optionsBuilder.UseSqlServer("Server=(local);Database=DBPrueba;Trusted_Connection=True;TrustServerCertificate=True;");
            }
        }

        protected override void OnModelCreating(ModelBuilder modelBuilder)
        {
            modelBuilder.Entity<Usuario>(entity =>
            {
                entity.HasKey(e => e.IdUsuario);
                
                entity.ToTable("Usuario");
                
                entity.Property(e => e.Correo)
                    .HasMaxLength(50)
                    .IsUnicode(false);
                    
                entity.Property(e => e.Nombre)
                    .HasMaxLength(50)
                    .IsUnicode(false);
                    
                entity.Property(e => e.Clave)
                    .HasMaxLength(200)
                    .IsUnicode(false);
                    
                entity.Property(e => e.Token)
                    .HasMaxLength(200)
                    .IsUnicode(false);
            });
        }
    }

    public partial class Usuario
    {
        public int IdUsuario { get; set; }
        public string Nombre { get; set; }
        public string Correo { get; set; }
        public string Clave { get; set; }
        public bool Restablecer { get; set; }
        public bool Confirmado { get; set; }
        public string Token { get; set; }
    }
}

4 Crear Modelos y DTOs

4.1 Crear DTOs (Data Transfer Objects)

Los DTOs se usan para transferir datos entre capas y para validación en las vistas. Crea la carpeta DTOs y agrega las siguientes clases:

UsuarioDTO.cs
using System.ComponentModel.DataAnnotations;

namespace WebAppCorreo.DTOs
{
    public class UsuarioDTO
    {
        public int IdUsuario { get; set; }

        [Required(ErrorMessage = "El nombre es requerido")]
        [StringLength(100, ErrorMessage = "El nombre no puede exceder 100 caracteres")]
        public string Nombre { get; set; } = string.Empty;

        [Required(ErrorMessage = "El correo es requerido")]
        [EmailAddress(ErrorMessage = "Formato de correo inválido")]
        [StringLength(150, ErrorMessage = "El correo no puede exceder 150 caracteres")]
        public string Correo { get; set; } = string.Empty;

        [Required(ErrorMessage = "La clave es requerida")]
        [StringLength(100, MinimumLength = 6, ErrorMessage = "La clave debe tener entre 6 y 100 caracteres")]
        public string Clave { get; set; } = string.Empty;

        [Compare("Clave", ErrorMessage = "Las contraseñas no coinciden")]
        [Display(Name = "Confirmar Clave")]
        public string? ConfirmarClave { get; set; }

        public bool Restablecer { get; set; }
        public bool Confirmado { get; set; }
        public string? Token { get; set; }
    }
}

4.2 Crear servicios de utilidad

Crea la carpeta Services y agrega la clase de utilidades:

UtilidadServicio.cs
using System.Security.Cryptography;
using System.Text;

namespace WebAppCorreo.Services
{
    public static class UtilidadServicio
    {
        public static string ConvertirSHA256(string texto)
        {
            string hash = string.Empty;

            using (SHA256 sha256 = SHA256.Create())
            {
                byte[] hashValue = sha256.ComputeHash(Encoding.UTF8.GetBytes(texto));

                foreach (byte b in hashValue)
                    hash += $"{b:X2}";
            }

            return hash;
        }

        public static string GenerarToken()
        {
            return Guid.NewGuid().ToString("N");
        }
    }
}
Nota:
  • La entidad Usuario ya fue generada automáticamente por EF Core en el Paso 3
  • Los DTOs se usan para las vistas y validación
  • La entidad Usuario se usa para acceso a datos
  • UtilidadServicio contiene métodos reutilizables para hashing y generación de tokens

5.2 Implementar servicios

UsuarioService.cs
using Microsoft.EntityFrameworkCore;
using WebAppCorreo.Data;
using WebAppCorreo.DTOs;
using WebAppCorreo.Interfaces;
using WebAppCorreo.Services;

namespace WebAppCorreo.Services
{
    public class UsuarioService : IUsuarioService
    {
        private readonly ApplicationDbContext _context;

        public UsuarioService(ApplicationDbContext context)
        {
            _context = context;
        }

        public async Task<bool> Registrar(UsuarioDTO usuario)
        {
            var nuevoUsuario = new Usuario
            {
                Nombre = usuario.Nombre,
                Correo = usuario.Correo,
                Clave = UtilidadServicio.ConvertirSHA256(usuario.Clave),
                Token = UtilidadServicio.GenerarToken(),
                Restablecer = false,
                Confirmado = false
            };

            _context.Usuarios.Add(nuevoUsuario);
            return await _context.SaveChangesAsync() > 0;
        }

        public async Task<UsuarioDTO?> Validar(string correo, string clave)
        {
            var usuario = await _context.Usuarios
                .FirstOrDefaultAsync(u => u.Correo == correo && u.Clave == clave);

            if (usuario == null)
                return null;

            return new UsuarioDTO
            {
                IdUsuario = usuario.IdUsuario,
                Nombre = usuario.Nombre,
                Correo = usuario.Correo,
                Restablecer = usuario.Restablecer,
                Confirmado = usuario.Confirmado
            };
        }

        public async Task<UsuarioDTO?> Obtener(string correo)
        {
            var usuario = await _context.Usuarios
                .FirstOrDefaultAsync(u => u.Correo == correo);

            if (usuario == null)
                return null;

            return new UsuarioDTO
            {
                IdUsuario = usuario.IdUsuario,
                Nombre = usuario.Nombre,
                Correo = usuario.Correo,
                Clave = usuario.Clave,
                Restablecer = usuario.Restablecer,
                Confirmado = usuario.Confirmado,
                Token = usuario.Token
            };
        }

        public async Task<bool> RestablecerActualizar(int restablecer, string clave, string token)
        {
            var usuario = await _context.Usuarios
                .FirstOrDefaultAsync(u => u.Token == token);

            if (usuario == null)
                return false;

            usuario.Restablecer = restablecer == 1;
            usuario.Clave = clave;

            return await _context.SaveChangesAsync() > 0;
        }

        public async Task<bool> Confirmar(string token)
        {
            var usuario = await _context.Usuarios
                .FirstOrDefaultAsync(u => u.Token == token);

            if (usuario == null)
                return false;

            usuario.Confirmado = true;

            return await _context.SaveChangesAsync() > 0;
        }
    }
}
CorreoService.cs
using MailKit.Net.Smtp;
using MailKit.Security;
using MimeKit;
using MimeKit.Text;
using WebAppCorreo.DTOs;
using WebAppCorreo.Interfaces;

namespace WebAppCorreo.Services
{
    public class CorreoService : ICorreoService
    {
        private readonly IConfiguration _configuration;

        public CorreoService(IConfiguration configuration)
        {
            _configuration = configuration;
        }

        public bool Enviar(CorreoDTO correoDTO)
        {
            try
            {
                var email = new MimeMessage();
                email.From.Add(new MailboxAddress(
                    _configuration["Smtp:NombreEnvia"] ?? "Sistema",
                    _configuration["Smtp:Correo"] ?? ""));
                email.To.Add(MailboxAddress.Parse(correoDTO.Para));
                email.Subject = correoDTO.Asunto;
                email.Body = new TextPart(TextFormat.Html)
                {
                    Text = correoDTO.Contenido
                };

                using var smtp = new SmtpClient();
                smtp.Connect(
                    _configuration["Smtp:Host"] ?? "smtp.gmail.com",
                    int.Parse(_configuration["Smtp:Port"] ?? "587"),
                    SecureSocketOptions.StartTls);

                smtp.Authenticate(
                    _configuration["Smtp:Correo"] ?? "",
                    _configuration["Smtp:Clave"] ?? "");

                smtp.Send(email);
                smtp.Disconnect(true);

                return true;
            }
            catch
            {
                return false;
            }
        }
    }
}
Nota:
  • Para usar MailKit, instala el paquete: Install-Package MailKit
  • Configura las credenciales SMTP en appsettings.json
  • Para Gmail, necesitas habilitar "Acceso a apps menos seguras" o usar App Passwords

6.2 Crear InicioController

using Microsoft.AspNetCore.Mvc;
using WebAppCorreo.DTOs;
using WebAppCorreo.Interfaces;
using WebAppCorreo.Services;

namespace WebAppCorreo.Controllers
{
    public class InicioController : Controller
    {
        private readonly IUsuarioService _usuarioService;
        private readonly ICorreoService _correoService;

        public InicioController(
            IUsuarioService usuarioService,
            ICorreoService correoService)
        {
            _usuarioService = usuarioService;
            _correoService = correoService;
        }

        // GET: Inicio/Login
        public IActionResult Login()
        {
            return View();
        }

        // POST: Inicio/Login
        [HttpPost]
        public async Task<IActionResult> Login(string correo, string clave)
        {
            var usuario = await _usuarioService.Validar(
                correo, 
                UtilidadServicio.ConvertirSHA256(clave));

            if (usuario != null)
            {
                if (!usuario.Confirmado)
                {
                    ViewBag.Mensaje = $"Falta confirmar su cuenta. Se le envió un correo a {correo}";
                }
                else if (usuario.Restablecer)
                {
                    ViewBag.Mensaje = $"Se ha solicitado restablecer su cuenta, favor revise su bandeja del correo {correo}";
                }
                else
                {
                    // TODO: Implementar JWT authentication aquí
                    return RedirectToAction("Index", "Home");
                }
            }
            else
            {
                ViewBag.Mensaje = "No se encontraron coincidencias";
            }

            return View();
        }

        // GET: Inicio/Registrar
        public IActionResult Registrar()
        {
            return View();
        }

        // POST: Inicio/Registrar
        [HttpPost]
        public async Task<IActionResult> Registrar(UsuarioDTO usuario)
        {
            if (usuario.Clave != usuario.ConfirmarClave)
            {
                ViewBag.Nombre = usuario.Nombre;
                ViewBag.Correo = usuario.Correo;
                ViewBag.Mensaje = "Las contraseñas no coinciden";
                return View();
            }

            var existe = await _usuarioService.Obtener(usuario.Correo);
            if (existe != null)
            {
                ViewBag.Mensaje = "El correo ya se encuentra registrado";
                return View();
            }

            bool respuesta = await _usuarioService.Registrar(usuario);

            if (respuesta)
            {
                string url = Url.Action("Confirmar", "Inicio", new { token = usuario.Token }, protocol: Request.Scheme);
                
                string htmlBody = $@"
                    <h2>Bienvenido {usuario.Nombre}</h2>
                    <p>Gracias por registrarte en nuestro sistema.</p>
                    <p>Para confirmar tu cuenta, haz clic en el siguiente enlace:</p>
                    <a href='{url}'>Confirmar Cuenta</a>";

                var correoDTO = new CorreoDTO
                {
                    Para = usuario.Correo,
                    Asunto = "Correo confirmación",
                    Contenido = htmlBody
                };

                bool enviado = _correoService.Enviar(correoDTO);
                ViewBag.Creado = true;
                ViewBag.Mensaje = $"Su cuenta ha sido creada. Hemos enviado un mensaje al correo {usuario.Correo} para confirmar su cuenta";
            }
            else
            {
                ViewBag.Mensaje = "No se pudo crear su cuenta";
            }

            return View();
        }

        // GET: Inicio/Confirmar
        public async Task<IActionResult> Confirmar(string token)
        {
            ViewBag.Respuesta = await _usuarioService.Confirmar(token);
            return View();
        }

        // GET: Inicio/Restablecer
        public IActionResult Restablecer()
        {
            return View();
        }

        // POST: Inicio/Restablecer
        [HttpPost]
        public async Task<IActionResult> Restablecer(string correo)
        {
            var usuario = await _usuarioService.Obtener(correo);
            ViewBag.Correo = correo;

            if (usuario != null)
            {
                bool respuesta = await _usuarioService.RestablecerActualizar(
                    1, 
                    usuario.Clave, 
                    usuario.Token);

                if (respuesta)
                {
                    string url = Url.Action("Actualizar", "Inicio", new { token = usuario.Token }, protocol: Request.Scheme);
                    
                    string htmlBody = $@"
                        <h2>Restablecer Contraseña</h2>
                        <p>Hola {usuario.Nombre}</p>
                        <p>Para restablecer tu contraseña, haz clic en el siguiente enlace:</p>
                        <a href='{url}'>Restablecer Contraseña</a>";

                    var correoDTO = new CorreoDTO
                    {
                        Para = correo,
                        Asunto = "Restablecer cuenta",
                        Contenido = htmlBody
                    };

                    bool enviado = _correoService.Enviar(correoDTO);
                    ViewBag.Restablecido = true;
                }
                else
                {
                    ViewBag.Mensaje = "No se pudo restablecer la cuenta";
                }
            }
            else
            {
                ViewBag.Mensaje = "No se encontraron coincidencias con el correo";
            }

            return View();
        }

        // GET: Inicio/Actualizar
        public IActionResult Actualizar(string token)
        {
            ViewBag.Token = token;
            return View();
        }

        // POST: Inicio/Actualizar
        [HttpPost]
        public async Task<IActionResult> Actualizar(string token, string clave, string confirmarClave)
        {
            ViewBag.Token = token;
            if (clave != confirmarClave)
            {
                ViewBag.Mensaje = "Las contraseñas no coinciden";
                return View();
            }

            bool respuesta = await _usuarioService.RestablecerActualizar(
                0, 
                UtilidadServicio.ConvertirSHA256(clave), 
                token);

            if (respuesta)
                ViewBag.Restablecido = true;
            else
                ViewBag.Mensaje = "No se pudo actualizar";

            return View();
        }
    }
}
Nota:

  • Todas las operaciones de base de datos son asíncronas (async/await)

  • Los correpos HTML se generan como strings para simplicidad

Implementar JWT Authentication

¿Por qué JWT?

JSON Web Tokens permiten autenticación stateless, escalabilidad horizontal, y son ideales para aplicaciones modernas. En lugar de sesiones en servidor, el token contiene toda la información necesaria.

1. Instalar paquete JWT desde Package Manager Console

Install-Package Microsoft.AspNetCore.Authentication.JwtBearer

2. Crear servicio JWT

using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Text;
using Microsoft.Extensions.Configuration;
using Microsoft.IdentityModel.Tokens;

namespace WebAppCorreo.Core.Services
{
    public interface IJwtService
    {
        string GenerarToken(string correo);
        ClaimsPrincipal? ValidarToken(string token);
    }

    public class JwtService : IJwtService
    {
        private readonly IConfiguration _configuration;

        public JwtService(IConfiguration configuration)
        {
            _configuration = configuration;
        }

        public string GenerarToken(string correo)
        {
            var key = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes(_configuration["Jwt:Key"]!));
            var creds = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

            var claims = new[]
            {
                new Claim(ClaimTypes.Email, correo),
                new Claim(JwtRegisteredClaimNames.Jti, Guid.NewGuid().ToString())
            };

            var token = new JwtSecurityToken(
                issuer: _configuration["Jwt:Issuer"],
                audience: _configuration["Jwt:Audience"],
                claims: claims,
                expires: DateTime.UtcNow.AddMinutes(
                    int.Parse(_configuration["Jwt:ExpirationInMinutes"]!)),
                signingCredentials: creds);

            return new JwtSecurityTokenHandler().WriteToken(token);
        }

        public ClaimsPrincipal? ValidarToken(string token)
        {
            var tokenHandler = new JwtSecurityTokenHandler();
            var key = Encoding.UTF8.GetBytes(_configuration["Jwt:Key"]!);

            try
            {
                var principal = tokenHandler.ValidateToken(token, new TokenValidationParameters
                {
                    ValidateIssuerSigningKey = true,
                    IssuerSigningKey = new SymmetricSecurityKey(key),
                    ValidateIssuer = true,
                    ValidIssuer = _configuration["Jwt:Issuer"],
                    ValidateAudience = true,
                    ValidAudience = _configuration["Jwt:Audience"],
                    ValidateLifetime = true,
                    ClockSkew = TimeSpan.Zero
                }, out _);

                return principal;
            }
            catch
            {
                return null;
            }
        }
    }
}

3. Configurar autenticación JWT en Program.cs

            ValidateIssuer = true,

            ValidateAudience = true,
            ValidAudience = builder.Configuration["Jwt:Audience"],

    });

using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.Filters;
using System.Security.Claims;

namespace WebAppCorreo.Core.Attributes
{
    public class JwtAuthorizeAttribute : Attribute, IAuthorizationFilter
    {
        public void OnAuthorization(AuthorizationFilterContext context)
        {
            var token = context.HttpContext.Request.Cookies["JWT"];
            
            if (string.IsNullOrEmpty(token))
            {
                context.Result = new RedirectToActionResult("Login", "Inicio", null);
                return;
            }

                .GetService<Services.IJwtService>();

            {
                context.Result = new RedirectToActionResult("Login", "Inicio", null);
            }
        }
    }
}

Implementar Rate Limiting

¿Por qué Rate Limiting?

Rate Limiting protege tu aplicación contra ataques de fuerza bruta, abuso de APIs, y sobrecarga del servidor. Es especialmente importante para endpoints de login y registro.

1. Instalar paquete NuGet

Install-Package Microsoft.AspNetCore.RateLimiting

2. Configurar Rate Limiting en Program.cs

using Microsoft.AspNetCore.RateLimiting;
using System.Threading.RateLimiting;

// ... después de builder.Services.AddDbContext()

// Configurar Rate Limiting
builder.Services.AddRateLimiter(options =>
{
    // Política para login (más estricta)
    options.AddPolicy("LoginPolicy", context =>
        RateLimitPartition.GetSlidingWindowLimiter(
            partitionKey: context.Connection.RemoteIpAddress?.ToString(),
            factory: _ => new SlidingWindowRateLimiterOptions
            {
                PermitLimit = 5,              // Máximo 5 intentos
                Window = TimeSpan.FromMinutes(5),  // En ventana de 5 minutos
                SegmentsPerWindow = 2,       // 2 segmentos por ventana
                QueueProcessingOrder = QueueProcessingOrder.OldestFirst,
                QueueLimit = 2               // Cola de 2 peticiones
            }));

    // Política general para la aplicación
    options.AddPolicy("GeneralPolicy", context =>
        RateLimitPartition.GetSlidingWindowLimiter(
            partitionKey: context.Connection.RemoteIpAddress?.ToString(),
            factory: _ => new SlidingWindowRateLimiterOptions
            {
                PermitLimit = 100,            // 100 peticiones
                Window = TimeSpan.FromMinutes(1),  // Por minuto
                SegmentsPerWindow = 2,
                QueueProcessingOrder = QueueProcessingOrder.OldestFirst,
                QueueLimit = 10
            }));

    // Configurar respuesta personalizada cuando se excede el límite
    options.OnRejected = async (context, cancellationToken) =>
    {
        context.HttpContext.Response.StatusCode = 429; // Too Many Requests
        await context.HttpContext.Response.WriteAsync(
            "Demasiadas solicitudes. Por favor, espera un momento.",
            cancellationToken);
    };
});
Explicación detallada de los parámetros:
PermitLimit = 5
  • ¿Qué Es? El número máximo de peticiones permitidas dentro del período de tiempo definido.
  • ¿Para qué se usa? Para establecer el límite máximo de solicitudes que un cliente puede realizar.
  • ¿Cómo se usa? Se configura como un valor entero en las opciones del limiter.
  • ¿Cuál es su beneficio? Previene abuso y ataques de fuerza bruta limitando el volumen de peticiones.
  • ¿Valores a configurar y por qué? Para login: 5-10 intentos. Para APIs generales: 100-1000. Valores bajos para endpoints sensibles, altos para endpoints públicos.
Window = TimeSpan.FromMinutes(5)
  • ¿Qué Es? La duración total de la ventana de tiempo en la que se cuentan las peticiones.
  • ¿Para qué se usa? Para definir el período de tiempo en el que aplica el límite de peticiones.
  • ¿Cómo se usa? Se configura usando TimeSpan (FromMinutes, FromSeconds, FromHours).
  • ¿Cuál es su beneficio? Permite controlar la frecuencia de peticiones en un período específico, evitando picos de tráfico.
  • ¿Valores a configurar y por qué? Login: 5-15 minutos. APIs: 1-60 minutos. Ventanas más largas para endpoints menos críticos, más cortas para sensibles.
SegmentsPerWindow = 2
  • ¿Qué Es? El número de segmentos en los que se divisiona la ventana de tiempo para cálculo más preciso.
  • ¿Para qué se usa? Para implementar el algoritmo de ventana deslizante (sliding window) con mayor precisión.
  • ¿Cómo se usa? Se configura como un valor entero que divide la ventana en segmentos iguales.
  • ¿Cuál es su beneficio? Evita picos repentinos al final de la ventana y proporciona un rate limiting más suave y preciso.
  • ¿Valores a configurar y por qué? 2-10 segmentos. Más segmentos = mayor precisión pero mayor consumo de memoria. 2-4 es un buen balance.
QueueProcessingOrder = OldestFirst
  • ¿Qué Es? Define el orden en que se procesan las peticiones que están en cola esperando ser atendidas.
  • ¿Para qué se usa? Para determinar la prioridad de procesamiento cuando hay peticiones en espera.
  • ¿Cómo se usa? Se configura con QueueProcessingOrder.OldestFirst o QueueProcessingOrder.NewestFirst.
  • ¿Cuál es su beneficio? OldestFirst garantiza fairness (las peticiones más antiguas se procesan primero). NewestFirst prioriza peticiones recientes.
  • ¿Valores a configurar y por qué? OldestFirst para la mayoría de casos (fairness). NewestFirst para sistemas donde las peticiones recientes son más relevantes.
QueueLimit = 2
  • ¿Qué Es? El número máximo de peticiones que pueden esperar en cola antes de ser rechazadas.
  • ¿Para qué se usa? Para definir la capacidad de la cola de espera cuando se excede el límite de peticiones.
  • ¿Cómo se usa? Se configura como un valor entero que representa el tamaño máximo de la cola.
  • ¿Cuál es su beneficio? Permite manejar picos breves de tráfico sin rechazar peticiones inmediatamente, mejorando la experiencia del usuario.
  • ¿Valores a configurar y por qué? 0-10 peticiones. 0 = sin cola (rechazo inmediato). Valores pequeños (2-5) para endpoints sensibles. Valores mayores para APIs públicas.

Comportamiento práctico con esta configuración: Un usuario puede hacer hasta 5 intentos de login en 5 minutos. Si excede ese límite, las siguientes 2 peticiones se ponen en cola. Si hay más de 7 peticiones (5 permitidas + 2 en cola), las adicionales se rechazan inmediatamente con HTTP 429.
